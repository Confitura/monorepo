# Logos

Official Confitura logo, converted from the RGB vector masters with clear space (one lid height) built in. Colours are fixed in the files: jam `#FF0040`, black `#000000`, white `#FFFFFF`. They don't follow CSS `color`.

- `confitura-logo.svg`: black wordmark and jam jar. For white grounds.
- `confitura-logo-reversed.svg`: white wordmark and jam jar. For `black` grounds and the dark theme.
- `confitura-logo-white.svg`: all white. For `jam` fills and dark photos only.
- `confitura-jar.svg`: the jar alone in jam. For favicons, avatars and stickers.
- `confitura-jar-white.svg`: the jar alone in white, for `jam` fills.
- `confitura-logo.png`, `confitura-jar.png`: transparent 6470px and 1799px originals for tools that can't take SVG. These include the original, wider margins.
