# Print

CMYK masters from the logo pack for printers: badges, roll-ups, banners and merch. Jam is CMYK 0/93/79/0 and black is K100. On screen use the SVGs in [`../logos/`](../logos/).

- `confitura-logo-cmyk.pdf`: black wordmark and jam jar on white.
- `confitura-logo-cmyk-on-jam.pdf`: all white on a jam ground.
- `confitura-logo-cmyk-on-black.pdf`: white wordmark and jam jar on black.
- `confitura-jar-cmyk.pdf`, `confitura-jar-cmyk-on-jam.pdf`, `confitura-jar-cmyk-on-black.pdf`: the jar alone, the same three ways.
